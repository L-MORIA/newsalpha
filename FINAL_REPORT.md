## Резюме

Проект **newsalpha** — воспроизведение метода STTM (PeerJ CS 2022) для прогнозирования
доходности акций на основе новостного анализа на российском рынке (MOEX).

**Результат: Метод НЕ работает на практике.**

- Код работает, пайплайн воспроизводим

### 2.2. Статистическая значимость ❌
- **Placebo p=0.50** — Sharpe не отличается от случайного
- **Direction accuracy 46-47%** — хуже случайного (50%)
- **p-value OOS > 0.10** — не значимо

### 2.3. Out-of-sample ❌
- **Sharpe -0.32** (weekly) / **-0.47** (daily)
- **MaxDD -48%** (weekly) / **-81%** (daily)
- **Direction accuracy < 50%** — метод предсказывает ХУЖЕ случайного

### 2.4. Сравнение с baseline ❌
- **AR(5) LogisticRegression** ≈ STTM по direction accuracy
- **Новости не лучше** ценовых данных

### 2.5. Дневная частота ❌
- **Daily Sharpe 0.22** (vs weekly 1.42) — в 6.5x хуже

- **Daily MaxDD -81%** (vs weekly -48%) — катастрофа

## 3. Почему метод не работает

### Корневая причина: cross-sectional selection

STTM-метод выбирает **топ-20% акций** по индексу. Этот механизм сам по себе
производит Sharpe ~1.4 за счёт:
- Диверсификации (8 акций из 39)
- Моментума (топ по индексу = растущие акции)
- Equal-weight portfolio на растущем рынке

**Placebo-тест показал:** случайный сигнал даёт такой же Sharpe (mean 1.48).
Новостной сигнал **не добавляет** предиктивной силы.

### Вторичные проблемы

| Проблема | Влияние |
|----------|---------|
| Корреляционный тон (pearson r) | Слабый, нестабильный |
| 50 тем LDA | Слишком много, размывает сигнал |
| Недельная агрегация | Шум, но daily ещё хуже |
| Vocabulary drift | Вторичный (Option B не помог) |

## 4. Научная ценность

### Положительные результаты

1. **Репликация:** воспроизвели статью (Sharpe 1.42 ≈ 1.37)
2. **Критика:** показали, что Sharpe = cross-sectional selection
3. **OOS:** показали, что метод не работает на новых данных
4. **Baseline:** AR(5) ≈ STTM — новости не лучше ценовых данных
5. **Negative result:** важен для науки (p-hacking, data snooping)

### Что это значит для поля

- **News-based weekly sentiment** не предсказывает доходность акций
- **Cross-sectional selection** топ-20% — мощный, но не связанный с новостями
- **Placebo-тесты** критически важны для оценки стратегий
