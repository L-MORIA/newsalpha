| Метрика | Option A (frozen) | Option B (full) |
|---------|-------------------|-----------------|
| Gross Sharpe | **-0.318** | **-0.232** |
| Direction Accuracy | ~46% | **46.2%** |

- Real Sharpe 1.42 vs placebo mean 1.48 ± 0.36
- **z = -0.16, p = 0.50** — НЕ значим
- **Вывод:** Sharpe = свойство кросс-секционного отбора топ-20%, а не новостей

## 2. Диагноз: почему метод не работает

### Корневая причина: временно́е разрешение

STTM агрегирует данные по **неделям**. Но эффект новостей на цены:
- Происходит за **часы** (внутри дня)
- Исчезает за **1-3 дня** (быстрое впитывание)
- На недельном горизонте новостной сигнал **размывается** случайным шумом

Это объясняет:
1. Почему placebo Sharpe = реальный Sharpe (кросс-секционный отбор работает на любой частоте)
2. Почему Direction Acc = 46% (на неделе сигнал уже не работает)
3. Почему OOS проваливается (overfitting на шуме)

### Вторичные проблемы

| Проблема | Влияние | Решаема ли |
|----------|---------|------------|
| Vocabulary drift | Среднее | Частично (Option B) |
| k=50 тем (слишком много) | Среднее | Да |
| Один источник (Ъ) | Низкое | Да (RBC, Interfax) |
| Корреляционный тон | Среднее | Да (supervised) |

## 3. Варианты плана (оценка)

### Option A: Дневное разрешение (Стратегия 1)
**Идея:** новостной эффект длится часы, а не недели. Пересчитать STTM на дневных данных.

| Параметр | Значение |
|----------|----------|
| Частота | D (дневная) |
| Сложность | Средняя |
| Ожидание | Низкое — шум внутри дня ещё сильнее |
| Время | 2-3 дня |
| Научная ценность | Средняя (проверка гипотезы о частоте) |

### Option B: Упрощённая LDA (Стратегия 2)
**Идея:** k=50 слишком много. Попробовать k=10-20, более чёткие темы.

| Параметр | Значение |
|----------|----------|
| k | 10, 15, 20 |
| Сложность | Низкая |
| Ожидание | Умеренное — чёткие темы = чётче сигнал |
| Время | 1-2 дня |
| Научная ценность | Средняя |

### Option C: Supervised Sentiment (Стратегия 3)
**Идея:** заменить корреляционный тон на supervised модель (обучена на historical returns).

| Параметр | Значение |
|----------|----------|
| Модель | LogReg / Ridge на word→return |
| Сложность | Средняя |
| Ожидание | Умеренное — но может дать overfitting |
| Время | 2-3 дня |
| Научная ценность | Высокая (новый метод) |

### Option D: Multi-source (Стратегия 4)
**Идея:** добавить RBC, Interfax → больше данных = больше сигнала.

| Параметр | Значение |
|----------|----------|
| Источники | Ъ + RBC + Interfax |
| Сложность | Высокая (скрапинг, дедупликация) |
| Ожидание | Низкое — проблема не в количестве данных |
| Время | 1-2 недели |
| Научная ценность | Высокая (трансферабельность) |

### Option E: Hybrid (Стратегия 5)
**Идея:** комбинировать новости с ценовыми фичами (volume, volatility, momentum).

| Параметр | Значение |
|----------|----------|
| Фичи | News + Price + Volume |
| Сложность | Средняя |
| Ожидание | Умеренное — но это уже не "news alpha" |
| Время | 3-5 дней |
| Научная ценность | Средняя |

### Option F: Negative Result Publication (Стратегия 6)
**Идея:** опубликовать негативный результат — это важно для науки.

| Параметр | Значение |
|----------|----------|
| Формат | Working paper / blog post |
| Сложность | Низкая |
| Ожидание | Готово уже |
| Время | 1-2 дня |
| Научная ценность | **Высокая** (честный негативный результат) |

## 4. Рекомендация: комбинированный план

### Приоритет 1: Negative Result (Option F) — 1-2 дня
**Почему首先:**
- Уже есть все данные
- Научная ценность = высокая
- Не требует дополнительных экспериментов
- Даёт основание для публикации

**Что делаем:**
1. Пишем short paper (3-5 страниц): "STTM on Russian Market: A Negative Result"
2. Включаем: воспроизведение (in-sample), placebo test, OOS, comparison with AR(5)
3. Вывод: "News-based weekly sentiment does not predict returns beyond random cross-sectional selection"
4. Публикуем на arXiv / SSRN / blog

### Приоритет 2: Daily Frequency (Option A) — 3-5 дней
**Почему следующий:**
- Проверяет ключевую гипотезу (временно́е разрешение)
- Если эффект есть — он на дневных данных
- Если нет — подтверждает негативный результат

**Что делаем:**
1. Адаптируем пайплайн для дневных данных
2. Пересчитываем STTM на daily frequency
3. Бэктест с теми же параметрами
4. Сравниваем с weekly результатами

### Приоритет 3: Simplified LDA (Option B) — 1-2 дня
**Почему третий:**
- Быстрый эксперимент
- Может улучшить signal-to-noise
- Низкие затраты

**Что делаем:**
1. Обучаем LDA k=10, 15, 20 на полном корпусе
2. Строим STTM с каждой моделью
3. Сравниваем Sharpes

### Приоритет 4: Supervised Sentiment (Option C) — 5-7 дней
**Почему четвёртый:**
- Самый перспективный, но сложный
- Требует careful cross-validation
- Риск overfitting

**Что делаем:**
1. Обучаем LogReg/Ridge на word→return (expanding window)
2. Заменяем корреляционный тон на supervised
3. Строим STTM с новым тоном
4. Кросс-валидация на train, бэктест на OOS

### Приоритет 5: Multi-source (Option D) — 2-3 недели
**Почему последний:**
- Самый сложный и длительный
- Проблема не в количестве данных
- Может быть полезен для robustness, но не для core signal

**Что делаем:**
1. Скрапинг RBC (ekonomika.rbc.ru)
2. Скрапинг Interfax (interfax.ru/business)
3. Дедупликация по дате + косинусной близости
4. Тестирование на полном корпусе

## 8. Научная ценность

**Даже если ничего не работает**, проект ценен:

1. **Репликация:** воспроизвели статью (Sharpe 1.42 ≈ 1.37)
2. **Критика:** показали, что Sharpe = cross-sectional selection (placebo p=0.50)
3. **OOS:** показали, что метод не работает на новых данных (Sharpe -0.32)
4. **Baseline:** AR(5) ≈ STTM → новости не лучше ценовых данных
5. **Negative result:** важен для науки (p-hacking, data snooping)

**Итог:** проект завершён как исследование, даже если торговый алгоритм не создан.
