## 5. Итоговый вывод

**STTM метод НЕ работает на out-of-sample данных 2022-2026:**

1. **Direction Accuracy 46.2%** — хуже случайного
2. **p=0.117** — не статистически значимо
3. **Sharpe -0.53** — катастрофический убыток
4. **MaxDD -55.6%** — теряет половину капитала

**Научное значение:**
- In-sample Sharpe 1.42 — результат overfitting
- Vocabulary drift — вторичная проблема (даже с полным словарём результат плохой)
- Cross-sectional selection (топ-20%) определяет Sharpe, а не новостной сигнал

**Рекомендация:** Метод не пригоден для реальной торговли без существенных доработок.
